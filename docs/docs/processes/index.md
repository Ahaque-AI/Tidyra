## When to add to this domain

- You are starting a new feature or refactor → write a plan, link it from here.
- You are making a decision that shapes the codebase → capture an ADR.
- You are fixing something non-trivial → log it in [known-issues](../known-issues/index.md).
- You are about to merge / release → follow the release flow in [processes.md](invariants/processes.md).
